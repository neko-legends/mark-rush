# Bundled Fonts

MarkRush bundles a small set of redistributable fonts so the document font
picker behaves consistently across Windows, macOS, and Linux.

Fonts:

- Noto Sans, from `google/fonts/ofl/notosans`
- Noto Serif, from `google/fonts/ofl/notoserif`
- Lora, from `google/fonts/ofl/lora`
- Poppins, from `google/fonts/ofl/poppins`
- Roboto Mono, from `googlefonts/RobotoMono`

Each bundled family is distributed under the SIL Open Font License 1.1. The
corresponding license text is included next to the font file.
